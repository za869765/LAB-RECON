# 檢驗對帳計算器 (LAB-RECON)

臺南市佳里區衛生所每月檢驗對帳工具。上傳 3 個來源檔，自動產出該月份的「檢驗總表」並校對廠商計算是否正確。

## 使用方法

1. 開啟 [`index.html`](index.html)（單檔離線 HTML，資料完全在你的瀏覽器本機處理，不上傳任何檔案到外部）
2. 拖曳或選擇 3 個檔案：
   - **央保對單**：`中央健保申報費和客戶對單_臺南市佳里區衛生所X.XLS`
   - **客戶帳單**：`客戶帳單明細_臺南市佳里區衛生所X.XLS`
   - **內部統計**：醫療系統匯出的 `YYYMM.xlsx`（交付檢驗統計表）
3. 按「▶ 產製檢驗總表 + 校對廠商」
4. 預覽結果無誤後按「📥 下載 檢驗總表-YYYMM.xlsx」

## 校對項目（7 項）

| # | 檢查 | 嚴重度 |
|---|---|---|
| 1 | 央保「客戶統計」金額 vs 每日小計加總 | 🔴 嚴重 |
| 2 | 央保「每日小計」vs 該日逐筆加總 | 🔴 嚴重 |
| 3 | 客戶帳單應收金額 vs 央保客戶統計（標準價） | 🔴 嚴重 |
| 4 | 客戶帳單 各筆加總 vs 應收金額 | 🟡 警示 |
| 5 | 央保 各代碼數量 vs 內部統計 | 🔴 多算 / 🟡 漏算 / 🔵 非此實驗室 |
| 6 | 央保各項目單價一致性（同月內同項不應有兩種價格）| 🔴 嚴重 |
| 7 | 廠商申報之單價 vs 115 年度契約標準價格表 | 🔴 廠商超收 / 🟡 廠商低收 |

第 7 項依據「**115 年度臺南市政府衛生局所屬各區衛生所臨床醫事檢驗委託服務案**」契約標準（內建約 60 個常見檢驗代碼），自動比對廠商申報之單價及健保支付點數是否一致。

- **v1.4.3** 「其他對帳表」忽略 IGRA（E4004C，送胸腔病院）—— `OTHER_TABLE_HIDE` 只隱藏顯示、仍留在 `NON_LAB_HINTS` 讓校對排除不誤報；合計改為只算 85（腸篩）+ 3F（胃篩）。
- **v1.4.2** 「帳單 vs 健保申報」差額**自動猜自費**：逐人比對帳單金額 vs 央保健保金額，帳單比央保多就點名（如「楊彩鳳 多 $109」=自費 HbA1C 不進健保申報），列為黃色提醒而非紅色未符合；總結列改成只有紅色才算「要處理」，純黃色顯示「金額都對、只是提醒」。
- **v1.4.1** ① 修正央保報表改版（115/6 起新增「健保代碼」欄、金額欄整個右移一格）導致 `parseCentral` 寫死欄位把代碼當金額（→0）、客戶統計總計也讀不到 → 全部金額 0、滿屏誤判。改為**依表頭名稱動態對欄**並用「健保代碼」欄直接判代碼（保留舊格式 fallback）。② 校對結果**全面白話化**：頂部一句總結（全部符合／N 項未符合）＋每項只說「符合／未符合」，未符合直接講「現在多少、應該多少、誰多收少報」。

- **v1.0.1** 加入內部短碼 → 央保長碼自動對照（`INTERNAL_CODE_ALIASES`，例如 `21 → 21013C`），避免同一項目誤判為「廠商多算 + 非此實驗室」。已知非此實驗室項目（85 大便潛血、E4004C、3F）顯示中文說明。

## 技術

- 純前端：HTML + Vanilla JS
- Excel 解析：[SheetJS](https://sheetjs.com/) (CDN)
- 民國年 YYYMM 格式（如 `11504` = 民國 115 年 4 月）
- 每月項目欄位自動依央保對單動態產出，項目少於 12 項或多於 17 項皆正常
